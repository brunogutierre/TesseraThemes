# Tessera Themes

Seasonal themes for [Tessera](https://brunogutierre.github.io/Tessera/): festive palettes and decorations that restyle every Tessera component from the outside, without forking it.

**Christmas** is the first theme; Halloween follows. Pick **Enterprise (Tessera base)** in the toolbar to see the same components undecorated.

Use the **Theme**, **Mode** and **Direction** menus in the toolbar to see every story in any combination.

## How it works

- **Themes** define every Tessera semantic token, in light and dark, and register with Tessera's typed theme registry.
- **Decoration** is CSS on Tessera's public styling API: host classes, state attributes, `data-tes-part` and component tokens.
- **New components** (`tt-*`) add what needs real markup: festive icons, seals, garlands and ambient effects.

Decoration never changes sizes or target areas, never carries information by itself, stops under reduced motion and disappears in forced colors and print.
